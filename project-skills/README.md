# project-skills

本目录存放 `db++` 仓库内的**项目级按需技能（Skills）**。

## 使用约定

- **仓内存储**：所有项目级 skill 统一放在 `project-skills/<name>/SKILL.md`，禁止写入外部目录（如 `~/.gemini/`）或隐藏目录（如 `.agents/`）。
- **按需检索与读取**：开始任务时仅根据任务范围匹配下表索引；**未命中对应领域时不要读取具体 `SKILL.md`**，避免无意义占用上下文。

## 索引

| Skill | 路径 | 何时读取 |
| --- | --- | --- |
| `dbpp-ui-layout` | [dbpp-ui-layout/SKILL.md](dbpp-ui-layout/SKILL.md) | 修改桌面端侧栏树缩进与关闭按钮、工作区 `SplitLayout` 分栏、WHERE 工具栏/底栏翻页或 Gemini 四色图标配色时 |
