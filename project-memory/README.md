# project-memory

本目录存放 `db++` 仓库内的**项目级持久化记忆**（架构决策、打包/CI 踩坑经验、框架注意事项与跨模块约定）。

## 使用约定

- **仓内存储**：所有项目级记忆统一写入本目录，禁止写入外部用户目录（如 `~/.gemini/`、`~/.claude/`）或隐藏目录（如 `.agents/`）。
- **按需读取**：仅在当前任务涉及对应领域时检索并读取相关记忆文件，禁止每次会话无条件全量加载。
