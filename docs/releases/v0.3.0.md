# db++ v0.3.0

次版本发布：新增中/英双语国际化（i18n）、多数据库四级层级侧栏与统一连接表单、密码框内嵌显示/隐藏眼睛图标、Windows/macOS 托盘菜单深色模式同步，并将项目与 CI 构建体系全面升级至 CMake >= 4.4 + C++23 Modules（`import std;`）。

## 变更与改进

- **中/英双语国际化（i18n）**：默认跟随系统语言，支持在设置页即时切换中/英文并持久化至 `dbpp.sqlite3`（`ui.language`），覆盖全部桌面 UI 与后端文案（318 条资源键），CLI 输出与 JSON schema 保持稳定。
- **多数据库层级侧栏与统一连接表单**：为 MySQL / PostgreSQL 等支持多库的连接按数据库/Schema 分类展示四级侧栏树（优先展示目标库、系统库默认折叠）；新增连接与编辑连接复用同一套表单字段组件，支持完整解析并编辑现有 URI、密码及附加查询参数。
- **密码输入框内嵌显示/隐藏图标**：将独立的显示密码复选框升级为 `PasswordField` 控件尾部内嵌眼睛图标（`visibility` / `visibility_off`），覆盖新建连接、编辑连接与 ADBC 管理器弹窗。
- **托盘菜单深色模式同步**：Windows（`uxtheme.dll` `SetPreferredAppMode` / `FlushMenuThemes`）与 macOS（`NSApp.appearance`）随应用/系统深浅色切换实时同步托盘菜单外观。
- **构建体系升级至 CMake >= 4.4 + C++23 Modules（`import std;`）**：将领域逻辑拆分为 10 个 C++23 模块（`dbpp_core`），仅保留 4 个薄 UI 壳头文件，并同步升级 GitHub Actions 多平台 CI/发版流水线。
