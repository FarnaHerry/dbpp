# db++ v0.3.2

补丁版本发布：优化侧栏树结构与数据库高亮交互，新增表格分页行数选择与多状态排序、顶部标题栏动作图标、统一居中加载动画控件，完善关于页图标与链接，并修复切换语言时设置标签页被关闭的问题。

## 变更与修复

- **侧栏树结构与视觉优化**：数据库按实际打开/展开状态高亮而非固定目标连接；所有树节点展开/收起图标统一为无尾尖括号；移除侧栏选中行前多余的竖线指示条；Redis 连接扁平展示数据库节点并移除多余分组层；SQLite 与 DuckDB 统一按默认 `main` 数据库分层显示。
- **表格分页每页行数选择与排序**：默认每页行数调整为 `100`，底部分页栏新增每页行数下拉菜单（支持 `50 / 100 / 200 / 500 / 1000`）；工具栏新增排序下拉菜单（选择列、切换升序/降序、清除排序），同时支持点击表头按「无排序 → 升序 → 降序 → 无排序」三态循环。
- **标题栏动作按钮图标与关于页更新**：为左上角「新建连接」「新建查询」「驱动管理」按钮补齐矢量图标；关于页外链行统一使用 GitHub Logo 并在 HuxerUI 下新增核心库 `Lib-DataTable` 仓库链接。
- **统一居中加载动画控件**：基于主题化 `ProgressCircle` 封装统一的 `LoadingState` 与 `LoadingOverlay` 控件，覆盖表浏览、SQL 控制台、表结构弹窗、编辑表结构、删除确认、ADBC 驱动管理、新建连接安装驱动与连接初始化等全部加载场景，并居中展示在各自内容区域中心。
- **修复语言切换关闭设置标签页**：保持 `AppShell` 始终包裹 `ProvideEnvironment`，避免在「跟随系统」与中文/英文之间切换时卸载并重建 `AppContent` 导致当前打开的设置页关闭。
