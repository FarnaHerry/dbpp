# db++ v0.4.10

补丁版本发布：修复 Linux 一键安装压缩包体积偏大与 Windows `install.ps1` 自检失败问题，并一并汇入此前未完成 GitHub Release 发布的 `v0.4.8` / `v0.4.9` 全部功能与修复（9 种数据导出/导入格式对齐、跨平台免提权一键安装脚本与 `PATH` 遮挡冲突提示、Redis 默认浏览视图设置）。

## 变更与修复

### Linux 便携包瘦身（`.tar.xz`）
- **修复符号链接重复与 ELF `strip`（`.github/workflows/build.yml`）**：
  - 避免 `Stage runtime bundle` 将已有 `libc++.so.1` / `libc++abi.so.1` 软链接覆盖成实体副本；
  - 对打包内的 `dbpp` 与 `lib/*.so*` 执行 `strip --strip-unneeded`；
  - 直接在 Linux 构建任务内保留软链接和可执行权限打包为 `.tar.xz`（`xz -T0 -6`），避免经 Actions Artifact 中转导致软链接解引用与权限丢失，体积显著小于同架构 `.deb` 与 `.rpm`。
- **`scripts/install.sh` 自动适配与向后兼容**：
  - Linux 下默认优先下载 `.tar.xz` 并以 `tar -xJf` 解压；若目标历史版本（如 `<= v0.4.7`）未提供 `.tar.xz` 或本机未安装 `xz`，自动回落下载 `.tar.gz`。

### Windows `install.ps1` 自检修复
- **兼容 `/SUBSYSTEM:WINDOWS` 可执行文件的 PowerShell 版本校验（`scripts/install.ps1`、`.github/workflows/build.yml`）**：
  - 改用 `System.Diagnostics.Process` 显式设置 `UseShellExecute = $false` 并重定向标准输出/错误执行 `dbpp.exe --version`，避免在 PowerShell 中直接调用 GUI 子系统可执行文件导致 `$LASTEXITCODE` 为空或误判失败，并在非零退出时输出十六进制退出码与详细信息。

### 合并此前 `v0.4.8` / `v0.4.9` 未发布功能（相比 `v0.4.7`）
- **9 种数据导出/导入格式全面对齐**：CSV、TSV、Excel (`.xlsx` 零外部依赖读写)、JSON、JSONL、SQL / SQL INSERT、Markdown、HTML、XML（覆盖 GUI 菜单与 `dbpp import` / `dbpp export` CLI）。
- **跨平台免提权一键安装/卸载与 `PATH` 遮挡检测**：支持 `curl | bash`（Linux/macOS）与 `irm | iex`（Windows），支持 `SHA256SUMS.txt` 校验、`PATH` 旧版本遮挡警告与保留用户数据的完整卸载。
- **Redis 默认浏览视图设置**：支持持久化表格/树状默认视图偏好至 `dbpp.sqlite3`。

## 一键安装

- **Linux / macOS**：
  ```sh
  curl -fsSL https://github.com/FarnaHerry/dbpp/releases/latest/download/install.sh | bash
  ```
- **Windows (PowerShell)**：
  ```powershell
  powershell -ExecutionPolicy ByPass -c "irm https://github.com/FarnaHerry/dbpp/releases/latest/download/install.ps1 | iex"
  ```
