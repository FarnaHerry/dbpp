# db++ v0.2.2

补丁版本：修复 Windows（尤其是中文 CP936/GBK 环境）下数据库连接失败弹出 Toast 时，因系统非 UTF-8 报错字节触发 HuxerUI 严格 UTF-8 校验异常而导致整个窗口异常的问题。

## 修复与改进

- **Windows Socket / DNS 报错转 UTF-8**：`src/redis_client.cpp` 在 Windows 下将 `FormatMessageA` 与 `gai_strerror` 替换为 `FormatMessageW` / `gai_strerrorW` 并转为 UTF-8，避免中文报错返回 GBK 字节。
- **ADBC / Arrow 错误文本转码与校验**：新增 `IsValidUtf8` / `SanitizeUtf8` 与 Windows `CP_ACP` → UTF-8 错误转码，覆盖 ADBC Driver Manager、数据库驱动错误及字符串单元格提取。
- **UI 文本入口全面兜底**：`NormalizeToastMessage`（Toast 通知）、`SingleLineCellPreview`（表格单元格预览）以及 `MutedText` / `ErrorText` 在交给 HuxerUI 渲染前统一确保合法 UTF-8，避免任何非法字节触发全屏错误页。
- **回归测试**：新增 GBK 字节、混合文本、非法 UTF-8 边界序列及表格预览清洗单元测试。
