# db++ v0.1.0

首个公开发布版本：SQLite 优先、基于 **Apache Arrow ADBC 25** 与 **HuxerUI** 构建的轻量级桌面数据管理器。

## 主要功能

- **SQLite 开箱即用**：内置编译期打包的 Apache Arrow ADBC SQLite 驱动（含 vendored SQLite3），无需单独安装数据库驱动即可直接打开或新建本地库文件。
- **ADBC 多数据库与 Manifest 发现**：支持连接 PostgreSQL、MySQL、DuckDB、Flight SQL 等任意 ADBC 驱动；兼容 `ADBC_DRIVER_PATH`、`DBPP_ADBC_DRIVERS`、虚拟环境及用户配置目录下的标准 `.toml` manifest 与共享库自动发现。
- **内置驱动注册表在线安装**：可在「ADBC 管理器」内直接浏览 ADBC Driver Registry、筛选驱动、查看下载进度、进行 SHA-256 校验、安全解压安装标准 `.toml` manifest，以及一键更新/卸载。
- **数据浏览、筛选与编辑**：基于 `Lib-DataTable` 的虚拟化表格，支持分页、`WHERE` 筛选、排序、行内编辑、添加行与删除行（SQLite 使用 `rowid`，其他数据库使用主键约束）。
- **SQL 控制台**：异步串行执行 SQL 查询与变更语句，展示结果集与影响行数，并自动刷新侧栏表/视图对象。
- **系统托盘与轻量级模式**：支持托盘常驻、轻量级关闭释放 UI/连接状态，以及极简黑白单色主题。
