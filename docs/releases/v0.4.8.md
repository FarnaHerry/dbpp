# db++ v0.4.8

补丁版本发布：全面对齐 9 种数据导出与导入格式（新增 TSV、Excel `.xlsx`、JSON、SQL / SQL INSERT、Markdown、HTML、XML）、上线跨平台免提权一键安装/卸载脚本与 `SHA256SUMS.txt` 发布校验，并新增 Redis 默认浏览视图持久化设置。

## 变更与修复

### 9 种全格式数据导出与导入对齐
- **统一覆盖 9 种主流格式**：CSV、TSV、Excel (`.xlsx`)、JSON、JSONL、SQL / SQL INSERT、Markdown、HTML、XML。
- **零外部依赖原生 Excel `.xlsx` 读写（`src/adbc_xlsx.cpp`、`src/adbc_ingest_xlsx.cpp`）**：
  - 导出端采用标准 OOXML + ZIP STORE + CRC-32 流式写入，支持首行冻结与表头样式、布尔/有限数值单元格，以及超出 JS 安全整数范围（`±9007199254740991`）的 64 位整数以 `inlineStr` 保留精确文本；
  - 复用 `dbpp.decoder` 导出的 `InflateRawDeflateBytes` 支持 ZIP STORE 与 DEFLATE 压缩 `.xlsx` 读取，完整兼容 `sharedStrings.xml`（含富文本）、稀疏单元格坐标及布尔/数值/内联字符串。
- **多格式解析与界面/CLI 一体化（`src/adbc_export.cpp`、`src/adbc_ingest_formats.cpp`）**：
  - 统一 GUI 导出/导入菜单分组（`src/ui/export_helpers.cpp`，接入 SQL 页、表浏览器与侧栏右键菜单）及中英双语资源；
  - `dbpp export` 与 `dbpp import` 均支持 `--type` 显式指定与按文件扩展名自动推断，支持 `--table <name>` 指定 SQL INSERT 目标表；
  - 新增 `tests/test_export_formats.cpp`（`test_export` 目标）与 `test_cli` 覆盖全格式导出→导入往返一致性与 JSON `\uXXXX` 代理对解码，CTest 7/7 全部通过。

### 跨平台一键安装脚本与 CI 发版增强
- **一键安装与卸载脚本（`scripts/install.sh` / `scripts/install.ps1`）**：
  - Linux (`x86_64` / `aarch64`) & macOS (`arm64`) 通过 `curl -fsSL ... | bash` 安装至用户级目录，支持 `SHA256SUMS.txt` 校验、原子目录替换、Linux `.desktop` 与图标集成、`--version` 自检与 `--uninstall`（保留 `dbpp.sqlite3` 与 ADBC 驱动）；
  - Windows (`x86_64`) 通过 `irm ... | iex` 安装至 `%LOCALAPPDATA%\Programs\dbpp`（兼容 PowerShell 5.1 / 7+），自动写入用户 `PATH`、创建开始菜单快捷方式、注册卸载项并支持 `-UseInstaller` / `-Uninstall`。
- **Windows WiX 安装器与 Release CI 优化**：
  - [Package.wxs.in](platform/windows/package/Package.wxs.in) 自动将安装目录加入系统 `PATH`；
  - `.github/workflows/build.yml` 统一 Linux 便携包结构并附带桌面文件、发布 `install.sh` / `install.ps1` / `SHA256SUMS.txt`，并在三平台 Runner 上增加安装脚本端到端冒烟验证。

### Redis 浏览视图偏好与对话框拆分
- 新增默认 Redis 浏览视图（表格 / 树状）偏好设置项并持久化至 `dbpp.sqlite3`（`redis.view_mode`），补充对应设置页控件与持久化单元测试；
- 拆分 `src/ui/redis_dialogs.cpp` 优化界面模块结构。

## 一键安装

- **Linux / macOS**：
  ```sh
  curl -fsSL https://github.com/FarnaHerry/dbpp/releases/latest/download/install.sh | bash
  ```
- **Windows (PowerShell)**：
  ```powershell
  powershell -ExecutionPolicy ByPass -c "irm https://github.com/FarnaHerry/dbpp/releases/latest/download/install.ps1 | iex"
  ```
