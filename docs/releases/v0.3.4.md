# db++ v0.3.4

补丁版本发布：为 SQL 读查询增加隐藏自动 `LIMIT` 保护、支持全界面自定义每页行数并持久化配置，并将 macOS 发布产物升级为 HuxerUI 原生 `.dmg` 镜像。

## 变更与修复

- **SQL 查询隐藏自动 `LIMIT`**：对未显式指定外层 `LIMIT` / `FETCH` / `OFFSET` / `TOP` 的单条 `SELECT` / 只读 `WITH` / `TABLE` 查询，在执行时自动隐藏附加 `\nLIMIT <page_size + 1>`（不修改编辑器原文），避免无限制查询扫描整表并精确提示是否有更多数据。
- **自定义每页行数与全局持久化**：新增可持久化的默认每页行数配置 `query.page_size`（范围 `1–100000`，默认 `100`）；表浏览底部分页器与查询页 `默认 LIMIT` 均改用支持直接输入任意行数的 `PageSizePopup` 弹窗，并在设置页「外观」分栏新增「查询与分页」配置项。
- **macOS 原生 `.dmg` 打包**：新增 `platform/macos/huxerui.cmake`，在 `CMakeLists.txt` 与 `.github/workflows/build.yml` 中接入 HuxerUI `HUXERUI_PACKAGE=ON` 安装部署与 `hdiutil` `.dmg` 打包流程，发布产物由 `.tar.gz` 升级为 `dbpp-0.3.4-macos-arm64.dmg`。
- **单元测试补充**：在 `tests/test_adbc_core.cpp` 中增加分页数解析/持久化校验及 `TestImplicitSqlLimitAndExecution`（含 SQL 词法边界与 SQLite 实际截断验证）。
