# db++ v0.4.0

次版本发布：全面挖掘并落地 Apache Arrow ADBC 1.0/1.1 与 Arrow C Data/Stream 原生能力，同时完成核心源码与 UI 模块化拆分重构、图标更新与 Linux RPM 打包优化。

## 主要特性与变更

### ADBC 1.0 / 1.1 与 Arrow 数据引擎增强
- **Arrow 复杂与扩展类型解析及流式导出**：
  - 支持 `LIST` / `LARGE_LIST` / `FIXED_SIZE_LIST`、`MAP`、`STRUCT`、`DENSE_UNION` / `SPARSE_UNION`、`DICTIONARY`、扩展类型 `arrow.uuid` 及高精度 `TIMESTAMP`（含时区）/`TIME` 递归格式化。
  - 基于 `ArrowArrayStream` 实现逐批流式导出（`ExportQueryStreamBlocking` / `ExportQueryToFileBlocking`），支持大结果集直接导出为 RFC-4180 CSV 或 JSONL，不受分页上限截断。
- **深度元数据、统计信息与命名空间**：
  - 增强 `GetObjects` 解析列默认值、注释、精度/标度、`UNIQUE`/`AUTOINCREMENT`/`GENERATED` 与外键引用（`ForeignKeyMeta`）及约束（`TableConstraintMeta`）。
  - 新增 `AdbcConnectionGetInfo`（驱动/引擎版本与 SQL 能力信息）、`AdbcConnectionGetTableTypes`、`AdbcConnectionGetStatistics` / `GetStatisticNames`、`AdbcStatementExecuteSchema`（不支持的驱动自动对只读查询退化 `LIMIT 0` 探测）以及原生 Catalog / Schema 命名空间切换。
- **查询取消、显式事务与只读会话**：
  - 实现 `AdbcSession::CancelActiveOperation` 支持执行中安全取消 SQL；统一提取结构化 `SQLSTATE`、`vendor_code` 与 `error_details`，基于 `08*`/`57P01..03` 判定连接断开。
  - 新增原生事务控制（`SetAutocommitBlocking`、`CommitTransactionBlocking`、`RollbackTransactionBlocking`、`SetIsolationLevelBlocking`）与只读连接选项（`ConnectionRequest::read_only`，SQLite 启用 `PRAGMA query_only = ON`）。
- **参数化预处理与 Arrow 批量导入 / 跨库复制**：
  - 新增 `AdbcStatementGetParameterSchema` 与 `AdbcStatementBind` 预处理绑定支持，并将行级 `UPDATE` / `DELETE` / `INSERT` 及批量提交优先切换至参数化执行（自动兼容回退 SQL 字面量）。
  - 实现 RFC-4180 CSV / JSONL 批量流式导入（`AdbcStatementSetOption` Bulk Ingest）与基于 `AdbcStatementBindStream` 的跨连接表复制（`CopyQueryToTableBlocking`）。

### GUI、CLI 与 MCP 集成
- **GUI 工作流升级**：
  - 对象结构对话框展示连接能力信息、列扩展属性、外键与驱动统计信息。
  - SQL 控制台新增执行取消按钮、事务控制菜单（Auto-commit / Begin / Commit / Rollback）、参数输入弹窗与流式 CSV/JSONL 导出；表浏览页新增 CSV/JSONL 导入与导出入口。
- **CLI 与 MCP 工具扩展**：
  - CLI 新增 `info`、`stats`、`import`、`export`、`copy` 子命令，以及 `query --param` / `--param-null` / `--schema-only` / `--read-only`，`schema --json` 补充外键与扩展列属性输出。
  - MCP 服务端新增 `get_connection_info`、`get_table_stats`、`inspect_query_schema` 工具，丰富 `describe_table` 信息，并透传只读配置至 `ConnectionRequest::read_only`。

### 架构模块化、打包与验证
- **代码模块化整理**：将原大型源文件按职责拆分为 `src/ui/`、`src/adbc_*.cpp`、`src/cli_*.cpp`、`src/db_*.cpp`、`src/mcp_server_*.cpp`、`src/redis_client_*.cpp`、`src/driver_installer_*.cpp`，所有 `.cpp` 源文件保持在 1000 行以内。
- **构建与打包修复**：刷新桌面端与托盘图标资源；在 `CMakeLists.txt` 与 `.github/workflows/build.yml` 中禁止 RPM 生成全局 `/usr/lib/.build-id/` 链接，避免多包冲突。
- **单元测试**：新增并扩展 `test_adbc_core`（`test_adbc_capabilities.cpp` 等）、`test_cli`、`test_mcp` 等测试，CTest 5/5 全部通过。
