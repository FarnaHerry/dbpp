# db++ v0.4.7

补丁版本发布：新增全局内置通用值解码器（`dbpp.decoder`），内置支持 JSON、Base64、Gzip / Zlib 压缩流（纯 C++23 RFC 1950/1951/1952 解压）、JWT、URL、Hex、Unicode 与时间戳解析及自动识别，并全面接入表格单元格查看/编辑、Redis 树状详情、SQL 结果预览与中英双语界面。

## 变更与修复

### 内置通用值解码器核心 (`dbpp.decoder`)
- **9 种内置解码模式（`ValueDecoderKind`）**：
  - `Raw`（原始文本）、`Json`（格式化与压缩 `MinifyJsonValue`）、`Base64`（含 URL-safe 与自动文本/压缩检测）、`Gzip`（纯 C++23 RFC 1950/1951/1952 Gzip / Zlib 解压 + 链式识别）、`Jwt`（Header / Payload / 过期时间格式化）、`Url`（Percent 解码 + 查询参数拆分）、`Hex`（十六进制文本/字节预览 + 链式解压）、`Unicode`（`\uXXXX` / `\UXXXXXXXX` 反转义）、`Timestamp`（秒/毫秒/微秒/纳秒时间戳转本地与 UTC 时间）。
- **纯 C++23 RFC 1950/1951/1952 解压实现**：
  - 在 `src/value_decoder_inflate.cpp` 内置无外部 zlib 依赖的 Deflate 解压器，校验 `CRC-32 / ISIZE` 与 `Adler-32`，并设置 `4 MiB`（`kMaxInflateOutputBytes`）解压输出上限以防止压缩炸弹内存溢出。
  - 支持对 Base64 与 Hex 编码载荷的自动链式 Gzip / Zlib 解压，以及解压后自动检测并格式化 JSON 内容。
- **智能格式探测（`DetectSuggestedDecoder`）**：
  - 根据单元格或键值内容特征自动推荐最匹配的解码器类型。

### 全界面解码预览集成与双语支持
- **统一 UI 解码组件（`src/ui/value_decoder_view.cpp`）**：
  - 集成至表格单元格编辑与详情对话框（`src/ui/table_edit_dialog.cpp`）、表浏览详情抽屉（`src/ui/schema_tables.cpp`）、Redis 树状分组详情面板（`src/ui/redis_tree_view.cpp`）及 SQL 查询结果浏览（`src/ui/sql_page.cpp`）。
- **中英双语文案与单元测试**：
  - 补充 `resources/strings/default.properties` 与 `resources/strings/zh.properties` 解码器界面字符串；
  - 新增 `tests/test_decoder.cpp` 并注册 `test_decoder` CTest 目标，覆盖全部 9 种解码模式与自动探测场景，CTest 6/6 全部通过。
