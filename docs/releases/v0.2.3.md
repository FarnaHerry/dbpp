# db++ v0.2.3

补丁版本：将应用设置与已保存连接统一迁移至 HuxerUI `Lib-SQLite`（`dbpp.sqlite3`），新增 15 种数据库专属矢量 Logo，支持连接默认保留密码与右键编辑连接，并同步更新 Windows 安装向导视觉主题与图标。

## 变更与改进

- **统一迁移至 HuxerUI `Lib-SQLite`（SQLite 3.53.4）**：应用设置与已保存连接统一存储在 `<data_dir>/dbpp.sqlite3`（WAL 模式、POSIX `0600` 权限），首次启动自动迁移旧版 `connections.tsv` / `settings.tsv` 并保留原文件；移除旧版内置 `third_party/adbc/c/vendor/sqlite3`（3.44.0），统一由 `Lib-SQLite` 提供 SQLite 源码。
- **15 种数据库专属矢量图标**：为 SQLite、PostgreSQL、MySQL、MariaDB、DuckDB、Redis、SQL Server、ClickHouse、Arrow Flight SQL、Snowflake、BigQuery、Trino、Databricks、Amazon Redshift 及自定义连接新增专属 SVG Logo，覆盖侧栏连接树、新建连接弹窗、ADBC 驱动管理、工作区标签与 SQL 页。
- **默认保留密码与右键编辑连接**：保存连接时默认保留密码（含 CLI `profile save --password/--password-env` 支持，列表仅展示 `has_password` 不回显明文）；点击连接直接尝试连接，不再重复弹窗询问密码；侧栏右键菜单新增「编辑连接…」，支持修改并直接保存或重连。
- **Windows 安装向导视觉更新**：`dbpp_installer` 同步最新 Gemini Spark 亮/暗双色主题与新版渐变 `dbpp_logo.png`。
