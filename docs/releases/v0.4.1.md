# db++ v0.4.1

补丁版本发布：升级表结构设计为多页签工作区标签页与横向带序号表格、接入 SQL / DDL 格式化与数据库 SQL 导入导出、修复单元格双击内联编辑及右键菜单，并增强连接环境安全与侧栏对象树浏览体验。

## 变更与修复

### 表结构标签页与横向结构视图
- **编辑表结构升级为工作区标签页**：移除原模态编辑表弹窗，侧栏右键「编辑表结构」直接打开 `TableDesign` 标签页，支持内联重命名表与 **DDL / 字段 / 索引 / 外键 / 触发器** 5 个页签切换（带 `#` 序号列、字段重命名/改类型/删列/新增列与 DDL 预览）。
- **查看表结构弹窗横向升级**：将「查看结构」弹窗升级为 `820px` 宽界面，提供 **字段 / 外键 / 统计信息** 页签切换，全部以带 `#` 序号列的横向 `DataTable` 展示。

### SQL / DDL 格式化与数据库 SQL 导入导出
- **无损 SQL / DDL 格式化器**：新增 `FormatSqlStatement` / `FormatSqlScript`，对表结构 **DDL** 页签、触发器/索引/视图/存储过程/事件定义及 SQL 导出脚本进行缩进、换行与 `CASE ... END` 安全排版，保留字面量、标识符与注释。
- **数据库与表导入导出**：左侧栏连接、数据库/Schema 及数据表右键菜单新增导出 SQL（结构和数据 / 仅结构）、导入 SQL 脚本及 CSV / JSONL 批量导入导出能力，并清理左侧栏冗余的展开/折叠右键项。

### 单元格编辑、NULL 展示与右键菜单修复
- **修复双击编辑与单元格右键菜单**：修复 HuxerUI 空 `View{}` 节点对账与 `PointerRoutePurpose::Input` 右键/指针拦截事件分发缺陷，并优化 `Lib-DataTable` 双击容差（450ms）与失焦提交竞态；移除冗余的「编辑整行」弹窗。
- **NULL 标识与单元格快捷操作**：新增可识别的 `NULL` 胶囊显示；在数据表与 SQL 结果页单元格右键菜单提供「设为 NULL」、复制单元格/整行及按值筛选；修复 SQLite 带主键表未正确回填 `NOT NULL` 约束的问题。

### 连接安全、对象树与配置持久化
- **环境模式与配置存储**：应用连接与设置统一持久化至 `dbpp.sqlite3`（WAL + 0600 权限）；连接支持只读模式、生产模式（`PROD` 徽章与写前二次确认）、系统库显示开关与备注。
- **侧栏对象树与时间本地化**：支持侧栏数据库级与表级对象展开（列、索引、外键、触发器、过程/函数、事件与保存查询）；支持时间戳字段按本地时区展示与回写标准化。
