# db++ v0.3.5

补丁版本发布：为 SQL 查询页补全与数据表浏览一致的底部分页导航（上一页 / 下一页 + 每页行数切换），并取消每页行数的 `100,000` 上限。

## 变更与修复

- **SQL 查询页底部分页与上下翻页**：
  - 将 SQL 查询页状态栏与分页控件统一移至页面最底部（与数据表浏览页对齐），提供每页行数选择器以及「上一页 / 下一页」按钮。
  - `ApplyImplicitSqlLimit` 支持分页偏移 `page`，对未显式指定 `LIMIT` / `OFFSET` / `FETCH` / `TOP` 的只读查询自动附加 `LIMIT <page_size + 1>` 与 `OFFSET <page * page_size>`，并准确显示当前页码及是否仍有更多数据。
  - 在查询页切换每页行数时自动回到第 1 页并重载当前查询，翻页期间保留既有列宽；切换连接或数据库、执行写语句时自动重置分页状态。
- **取消每页行数 `100,000` 上限**：
  - `kMaxPageSize` 由 `100000` 放宽至 `INT64_MAX - 1`，任意大于等于 `1` 的整数均可作为每页行数及 SQL 自动 `LIMIT` 生效，并更新设置页与自定义弹窗提示文案。
  - 修复大分页数场景下表浏览总页数与 SQL / Redis `OFFSET` 计算的潜在整数溢出问题。
- **单元测试补充**：在 `tests/test_adbc_core.cpp` 中扩展大分页数解析/持久化校验及多页 SQL 自动 `LIMIT` + `OFFSET` 分页执行验证。
