# db++ v0.3.6

补丁版本发布：修复分页大小切换后未即时应用并重载页面的问题，并在查询页与表浏览页底部状态栏左侧新增执行耗时与实际 SQL 审计展示。

## 变更与修复

- **分页大小切换即时应用与刷新**：
  - 设置页「查询与分页」应用默认每页行数后，立即同步到 `AppModel` 与所有已打开的表浏览页 / SQL 查询页并从第 1 页触发重载（保留含未提交新增草稿的表页不打断编辑）。
  - 抽取共享执行函数 `ExecuteSqlTabQuery`，确保 SQL 查询页切换分页数时无论之前是否处于分页模式均立即重查并写入当前标签页 `page_size`；`RequestLoadTable` 与 `OpenSqlTab` 初始化/加载时即时同步 `page_size`。
  - 移除侧栏「在 SQL 编辑器中查询」生成语句中硬编码的 `LIMIT 100;`，并调整 `PageSizePopup` 回调在弹窗关闭前触发 `on_apply`。
- **底部状态栏基础审计信息**：
  - 在 `ExecuteBlocking`、`LoadTableBlocking` 与 `LoadRedisTableBlocking` 中统计微秒级执行耗时（覆盖 ADBC、Redis 及断线重连重试路径）并记录实际执行的完整 SQL / `SCAN` 语句（包含隐式补充的 `LIMIT` / `OFFSET`）。
  - 在 SQL 查询页与数据表浏览页底部状态条左侧统一显示耗时徽章（`FormatExecutionDuration`）与单行省略的实际执行 SQL 胶囊（`CompactSqlPreview`），支持悬停 `Tooltip` 查看全文及点击一键复制到剪贴板。
- **单元测试补充**：在 `tests/test_adbc_core.cpp` 中增加耗时格式化、SQL 紧凑预览截断、以及 `ExecuteBlocking` / `LoadTableBlocking` 耗时与审计 SQL 记录断言。
