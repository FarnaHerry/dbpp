# db++ v0.3.3

补丁版本发布：为统一加载控件增加防闪烁延迟，并在查询页执行按钮左侧新增连接与数据库双选择器，支持在同一查询标签页内切换连接并精确指定目标库/Schema 执行。

## 变更与修复

- **加载动画防闪烁延迟**：为统一加载控件 `LoadingState` 与 `LoadingOverlay` 增加默认 `200ms` 延迟展示（`kDefaultLoadingDelayMs`），在延迟内完成的快速操作自动取消计时器，避免加载动画一闪而过。
- **查询页连接与数据库双选择器**：在查询页执行按钮左侧新增「选择连接」与紧邻右侧的「选择数据库」下拉菜单，支持在已打开会话之间切换以及直接连接并切入未连接的已保存配置；执行前按方言自动切换目标库/Schema 上下文（MySQL `USE`、PostgreSQL `SET search_path TO`、DuckDB/通用 SQL `USE`、Redis `EnsureDb`，SQLite 保持默认），并在 Redis 控制台执行 `SELECT` 后同步选择器状态。
- **单元测试与双语完善**：新增 `sql_select_connection`、`sql_select_database`、`sql_conn_offline_tag` 双语文案，并补充 `TestSqlDatabaseContextHelpers` 单元测试覆盖多方言数据库列表、默认库选择与切换 SQL 生成。
