# db++ v0.3.1

补丁版本发布：修复连接状态检测、RAII 资源管理与 SQL 筛选不生效问题，新增表结构编辑、工作区化三分栏设置页（外观 / MCP / 关于）、嵌入式本地 MCP HTTP 服务器及界面图标/标签栏交互增强。

## 变更与修复

- **连接状态同步与 RAII 资源管理**：使用 RAII 守卫管理 ADBC 语句、数组/流与 Redis/SQLite 句柄；为各查询/元数据结果增加 `connection_lost` 状态判定，新增 15 秒周期健康检查，断连自动同步状态并支持单次安全重连。
- **修复应用 SQL 筛选不生效**：实现 `NormalizeSqlFilter`（自动清理空白、前导 `WHERE ` 与末尾分号），为表格视图增加 `snapshot_version` 键刷新与筛选清除/状态角标/错误提示。
- **右键菜单编辑数据库表**：为非只读 SQL 表新增「编辑表结构…」弹窗，支持表重命名、新增列、重命名列、删除列、非 SQLite 方言列类型修改与 DDL 实时预览，所有操作均在 ADBC 串行队列异步执行。
- **设置页标签化与三分栏重构**：将设置页抽象为工作区标签页，左侧按「外观」「MCP」「关于」分栏；关于页展示软件信息及 db++、HuxerUI、Apache Arrow ADBC 的 GitHub 仓库链接。
- **本地 MCP HTTP 服务器**：新增 `dbpp.mcp` 模块，通过 `dbpp.sqlite3` 持久化启停、监听地址/端口与只读保护设置，在 `POST /mcp`（与 `GET /health`）提供 Streamable HTTP JSON-RPC 2.0 服务并内置 `list_profiles`、`list_tables`、`describe_table`、`run_query` 工具。
- **图标与导航/标签栏体验提升**：为数据库、表、视图、物化视图、外部表、SQL 控制台等补齐单色矢量图标；左侧栏移除「数据库连接」标题并改为连接搜索过滤框；工作区标签栏支持鼠标滚轮横向滚动，并在 `＋` 按钮旁新增带搜索的「全部标签页」下拉列表。
