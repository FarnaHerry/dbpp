# db++ v0.4.4

补丁版本发布：实现表格直接编辑与删除行的乐观暂存、事务批提交及失败自动事务回滚，开放全列「设为 NULL」右键菜单并将多层只读/生产保护与事务通道收束统一。

## 变更与修复

### 表格乐观编辑 / 删除与短事务批提交
- **单元格乐观暂存与「设为 NULL」全开放 (`PendingCellEdit` / `StageTableCellEdit`)**：
  - 双击内联修改、编辑单元格弹窗及右键「设为 NULL」（已对可编辑表中包括 `NOT NULL`、主键与 BLOB 在内的所有单元格开放，并将约束检查延后至提交阶段）均直接暂存至待提交修改集并立即在表格显示目标值（`draft_accent` 高亮与原值→新值提示）；点击右上角「提交」时自动刷新仍在焦点中的编辑器内容。
- **乐观删除行（Gemini 红 + 删除线）(`pending_deletes` / `ToggleTableRowPendingDelete`)**：
  - 删除已提交行不再弹出阻断确认窗口，直接以 Gemini 红（`semantic.danger`）+ 删除线（`TextDecoration::StrikeThrough`）与淡红底色高亮显示 `#` 序号列与整行单元格，工具栏与右键菜单同步提供「撤销删除」。
- **提交短事务与失败保留暂存 (`CommitTableChangesBlocking` / `RequestCommitTableChanges`)**：
  - 点击右上角「提交 (N)」时开启数据库短事务，同一行多列修改合并为单条 `UPDATE`（跳过已标删行），并与 `DELETE`、`INSERT` 同批原子提交。
  - 提交失败时数据库事务自动 `ROLLBACK`，界面保留暂存修改与删除标记并弹出错误 Toast，由用户决定继续修改重试或点击「回滚」放弃。

### 多层写保护与执行结构收束
- **UI 统一写守卫 (`RunGuardedWrite`)**：抽离只读连接拦截与生产模式二次确认逻辑，统一接管表格提交、CSV/JSONL 导入、SQL 导入、表结构 DDL 与 SQL 控制台写操作，并移除冗余直写路径（`RequestSaveCell`、`RequestDeleteSelected`、`DeleteRowDialog`）。
- **后端事务与预处理回退收束 (`ScopedTransaction` / `ExecuteWriteWithFallback`)**：统一 `UPDATE` / `INSERT` / `DELETE` 的预处理与字面量回退通道，以及 RAII 事务管理与回滚清理。
- **单元测试补充**：在 `tests/test_adbc_capabilities.cpp` 第 20 节新增同事务多列更新 + 删行覆盖 + 新增提交与唯一键冲突整批事务回滚测试，CTest 5/5 全部通过。
