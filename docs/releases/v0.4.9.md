# db++ v0.4.9

补丁版本发布：为跨平台一键安装脚本补充 `PATH` 遮挡冲突检测与提示，避免旧版系统安装包与用户级安装并存时终端调用错位。

## 变更与修复

### 一键安装脚本 `PATH` 遮挡冲突提示
- **Linux / macOS（`scripts/install.sh`）**：
  - 安装完成并验证 `--version` 后，检查 `command -v dbpp` 实际命中的路径（规范化对比）；
  - 若命中的路径与刚安装的 `~/.local/bin/dbpp` 不一致，输出明确的 `PATH` 遮挡警告；
  - 若发现被 `/usr/bin/dbpp` 遮挡，提示用户可卸载旧版系统包（`sudo apt remove dbpp` 或 `sudo dnf remove dbpp`）或将 `~/.local/bin` 置于 `PATH` 更靠前的位置。
- **Windows（`scripts/install.ps1`）**：
  - 安装完成并验证 `--version` 后，通过 `Get-Command dbpp` 检查当前 `PATH` 解析优先级；
  - 若其它目录（如系统安装包位于 `Program Files\db++`）的 `dbpp.exe` 排在新装目录之前，输出警告提示避免误调用旧版本。

## 一键安装

- **Linux / macOS**：
  ```sh
  curl -fsSL https://github.com/FarnaHerry/dbpp/releases/latest/download/install.sh | bash
  ```
- **Windows (PowerShell)**：
  ```powershell
  powershell -ExecutionPolicy ByPass -c "irm https://github.com/FarnaHerry/dbpp/releases/latest/download/install.ps1 | iex"
  ```
