# db++ v0.2.1

补丁版本：精简空白首页操作入口，全面加固 Redis 连接分派、凭据脱敏、协议兼容性与命令台执行体验（已通过本地 Redis 7.4.11 实测验证）。

## 修复与改进

- **空白页精简**：移除首页「打开数据库…」按钮，统一保留「新建连接…」主入口。
- **Redis 方言分派修复**：`redis://` / `rediss://` URI 优先按协议分派，不再因驱动路径包含默认 SQLite 动态库而被误判为 SQLite 文件。
- **URI 组装与凭据安全**：
  - 修复表单模式中主机栏粘贴完整 URI 或 `host:port` 时被误包成 IPv6 `[...]` 并重复拼接端口的问题；
  - 在保存连接至 `connections.tsv` 前自动剥离 URI 内嵌密码，密码仅随连接请求在内存中传递，同时确保 `redis://` / `rediss://` 已保存配置在点击连接时正确触发密码确认。
- **Redis 协议与云实例兼容**：
  - `ParseRedisUri` 支持 `/dbN` 与 `?db=dbN` 数据库编号写法；
  - 兼容 Redis < 6.0 单参数 `AUTH <password>` 自动回退与 Redis 6+ ACL `nopass` 自定义用户名；
  - 对象列表枚举改为分步容错执行（`INFO keyspace` → `CONFIG GET databases` → 回退 `DBSIZE`），避免代理或云 Redis 禁用 `CONFIG` 断连时整体失败。
- **Redis 命令台增强**：支持首行 `#` 注释与多行命令顺序执行（失败时定位具体行号），并修复混合读写脚本下 `--read-only` 的只读判定。
