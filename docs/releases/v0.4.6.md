# db++ v0.4.6

补丁版本发布：针对 Redis 数据浏览进行全面性能优化与交互升级，新增大键值安全预览、原生 `SCAN ... TYPE` 类型筛选、优化表格列顺序，并推出支持自定义分隔符嵌套分组的 Redis 树状视图与按需详情面板。

## 变更与修复

### Redis 大键值安全预览与扫描保护
- **三段式安全预览管线**：将列表值读取拆分为 `TYPE`/`TTL` → $O(1)$ 长度探测（`STRLEN`/`HLEN`/`LLEN`/`SCARD`/`ZCARD`/`XLEN`）→ 按大小分级读取，避免大键直接拉爆内存或阻塞实例：
  - `string > 65536` 字节自动降级为 `GETRANGE 0 65535`，并安全裁剪末尾被截断的多字节 UTF-8 字符；
  - `hash / set > 200` 项改用 `HSCAN` / `SSCAN` 采样预览，不再触发全量 `HGETALL` / `SMEMBERS`；
  - `list / zset / stream` 明确标注预览截断信息。
- **表内截断防误覆盖**：在 `UpdateRedisCellBlocking` 中拦截对截断大键 `value` 列的直接覆盖修改，提示改用命令台编辑以免数据丢失；键名重命名、TTL/PERSIST 与删除保持可用。
- **`SCAN` 批上限与取消接入**：新增 `kRedisMaxScanIterations = 200` 批扫描上限及会话取消标志接入，避免低命中 `MATCH` 在大库上长时间空扫。

### Redis 原生类型筛选与表格列顺序优化
- **表格列顺序调整**：将 Redis 表结构统一调整为 `key, value, type, ttl, size`，打开后无需横向滚动即可在 `key` 后直接查看 `value`。
- **类型筛选（GUI + CLI）**：
  - `LoadRedisKeysPageBlocking` 与 `ScanRedisKeyNamesBlocking` 支持 `SCAN ... TYPE <type>` 服务端过滤，并在 Redis < 6.0 返回 `ERR syntax error` 时自动回退至客户端 Pipeline `TYPE` 过滤；
  - 表格工具栏新增类型选择器与状态徽章，CLI `dbpp rows` 新增 `--type <redis-type>` 参数。

### Redis 树状分组视图与单键详情面板
- **表格 / 树状视图一键切换**：新增 `RedisViewModeSwitch`，可在同一标签页工具栏中无缝切换。
- **自定义分隔符嵌套分组树**：
  - 树状视图仅扫描排序键名（不预拉任何值/长度/TTL），支持 `:`、`/`、`.`、`-`、`_`、平铺及自定义任意分隔符（`RedisDelimiterFilterButton`）多级嵌套展示与全树展开/折叠；
  - 右侧详情面板在选中键时按需加载元数据与内容，支持重命名、`TTL / 永不过期` 设置、`string` 大值加载完整内容与保存（`KEEPTTL`），以及 `hash`/`list`/`set`/`zset`/`stream` 结构化表格查看。
- **测试覆盖**：在 `tests/test_redis.cpp` 与 `test_redis_mock.cpp` 新增 `GETRANGE`/`HSCAN`/`SSCAN`/`SCAN ... TYPE` mock 支持及大键、扫描上限、类型过滤、树状分组与详情写入测试，CTest 5/5 全部通过。
