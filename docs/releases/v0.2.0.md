# db++ v0.2.0

第二版公开发布：在 SQLite 与 Apache Arrow ADBC 基础上新增内置零依赖 Redis（RESP2/RESP3）支持、「Gemini 星光」多预设主题、多标签页工作区及无头 CLI 能力。

## 主要功能

- **内置零依赖 Redis（RESP2/RESP3）支持**：
  - GUI 新建连接向导支持主机、端口、用户名/密码与 TLS/DB 选择；
  - 左侧显示 `db0`..`db15` 数据库树，右侧提供基于 `SCAN MATCH` 的分页/排序键浏览器；
  - 支持 String（保留 `KEEPTTL`）、Hash/List/Set/ZSet 的 JSON 内联编辑、TTL 调整、`RENAMENX` 改名与批量新建/删除键；
  - 内置 Redis 控制台，并支持无头 CLI `--redis` 操作。
- **「Gemini 星光（Gemini Spark）」多预设主题与全新品牌图标**：
  - 提供 5 套配色预设与跟随系统 / 深色 / 浅色模式切换，配置持久化至 `settings.tsv`；
  - 全面焕新蓝紫珊瑚渐变品牌图标（`.ico` / `.icns` / `.png`），并在 `run.sh` 中支持 Linux XDG 图标自动同步。
- **工作区与表格编辑体验升级**：
  - 支持多标签页工作区与连接列表拖拽排序（单纯点击不改变顺序）；
  - 表格支持单行省略、自动列宽与手动拉伸列宽保留；
  - 增强底部分页与内联空白草稿行批量事务提交。
- **无头 CLI 与桌面单实例唤醒**：
  - 新增完整无头 CLI 子命令（`doctor` / `driver` / `profile` / `tables` / `schema` / `rows` / `query` / `exec` / `sql`），支持 `--json` 结构化输出；
  - 支持桌面端单实例检测与唤起已有窗口。
