安装与软件源 GPG 公钥 setup-repo.sh

安装与软件源

免管理员权限安装到 ~/.local/opt/dbpp（macOS 为 /Applications/dbpp.app），自动校验 SHA-256 与注册桌面图标：

curl -fsSL {{REPO_URL}}/releases/latest/download/install.sh | bash

卸载（保留 dbpp.sqlite3 与已装驱动）：install.sh --uninstall

配置官方 GPG 签名软件源（安装到 /opt/dbpp，支持 dnf / apt / zypper 随系统自动更新）：

curl -fsSL {{BASE_URL}}/setup-repo.sh | sudo bash

GPG 公钥指纹：{{GPG_FPR}} · gpg.key

查看手动配置 Fedora/RHEL (dnf) 与 Debian/Ubuntu (apt) 命令 
# Fedora / RHEL (x86_64 & aarch64)
sudo rpm --import {{BASE_URL}}/gpg.key
sudo tee /etc/yum.repos.d/dbpp.repo <<'REPO'
[dbpp]
name=db++ Repository
baseurl={{BASE_URL}}/rpm/$basearch/
enabled=1
gpgcheck=1
repo_gpgcheck=0
gpgkey={{BASE_URL}}/gpg.key
REPO
sudo dnf install -y dbpp
# Debian / Ubuntu (amd64 & arm64)
curl -fsSL {{BASE_URL}}/gpg.key | sudo gpg --dearmor -o /etc/apt/keyrings/dbpp.gpg
echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/dbpp.gpg] {{BASE_URL}}/apt stable main" | sudo tee /etc/apt/sources.list.d/dbpp.list
sudo apt update && sudo apt install -y dbpp

在 PowerShell 下免管理员权限安装到 %LOCALAPPDATA%\Programs\dbpp（自动写入用户 PATH 与开始菜单）：

irm {{REPO_URL}}/releases/latest/download/install.ps1 | iex

加 $env:DBPP_USE_INSTALLER='1' 可改用 WiX 图形安装向导；卸载设 $env:DBPP_UNINSTALL='1'。

无需图形界面即可查询、导出/导入、在线管理 ADBC 驱动，支持 --json 结构化输出：

dbpp doctor --json
dbpp tables --sqlite ./app.sqlite --json
dbpp query  --sqlite ./app.sqlite "SELECT * FROM items LIMIT 20" --json
dbpp export --sqlite ./app.sqlite "SELECT * FROM items" --out items.xlsx
dbpp import --sqlite ./app.sqlite items items.xlsx --mode create_append

核心特性

SQLite 优先 & ADBC 多数据库

开箱内置 SQLite 驱动，统一通过 Apache Arrow ADBC 接入 PostgreSQL、MySQL、DuckDB、FlightSQL 等，并支持应用内浏览和在线安装驱动。

零依赖内置 Redis 客户端

原生 RESP2/RESP3 TCP 客户端，按 db0..db15 分类浏览，支持树状/表格双视图、String/Hash/List/Set/ZSet 编辑、TTL 管理与命令控制台。

9 种格式导入 / 导出对称支持

全面支持 CSV、TSV、Excel (.xlsx)、JSON、JSONL、SQL INSERT、Markdown、HTML、XML，GUI 右键菜单与 CLI 一体化零外部依赖读写。

虚拟化表格 & 多标签 SQL 页

Lib-DataTable 单行高密度虚拟表格、内联编辑、空白草稿行事务提交/回滚、底部分页与排序筛选，同屏保留多个表与 SQL 查询标签页。

无头 CLI & MCP 就绪

无显示环境也可直接执行查询、管理 dbpp.sqlite3 连接配置与驱动，所有指令提供结构化 --json 输出并内置 MCP 服务能力。

轻量级托盘 · 5 套主题 · 双语界面

单实例唤醒、关闭最小化托盘或轻量级模式释放窗口与连接、5 套主题预设（含 Gemini 星光）深浅色同步及中/英实时切换。
